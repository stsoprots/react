// ==== Підсумок проєкту /tanstack-query-4 ======

Проект налаштовує зв'язку React + TanStack Query і вирішує три завдання:

1)Глобальна інфраструктура (main.tsx, useQueryClientConfig.ts): створює та надає всьому застосунку клієнт React Query з автоматичним логуванням у консоль будь-яких успішних відповідей (як запитів, так і мутацій) та перезапитом даних при активації вікна браузера. 
2)Отримання та показ даних (App.tsx): завантажує перші 5 постів (limit: 5, offset: 0) через useGetPaginatedPosts, показує екран завантаження (Loading ...) і відображає поля постів (id, title, body, userId).
3)Створення запису (App.tsx): по кліку на кнопку відправляє тестовий пост на сервер через мутацію createPostRequest.
